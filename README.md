# Agencia

La oficina de la agencia de automatización con IA. Abrí este repositorio en Claude Code y pedí cosas como:

- "Director, ¿en qué estamos?"
- "Ventas, investigá a [prospecto] y armá el mensaje de primer contacto"
- "Analista, con estas notas armá el brief de [cliente]"
- "Desarrollador, construí el cotizador según el brief de [cliente]"
- "Crítico, revisá la entrega de [cliente]"

Las reglas y el contexto completo están en `CLAUDE.md`. Los agentes, en `.claude/agents/`.
